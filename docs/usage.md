# 使用指南

## 1. 创建研究方向

启动后在首页选择或新增方向，例如“检索增强生成”。填写具体研究描述，检索关键词建议使用英文，如 `retrieval augmented generation`，并按需要设置排除词、arXiv 分类、作者和会议偏好。关键词过宽会增加噪声，过窄可能漏掉论文。

点击“获取最新论文”，在更新记录中查看来源状态与获取结果。推荐数是上限，相关候选不足时不会凑数。每日任务要求服务运行且电脑处于唤醒状态；具体时间在设置中调整。

## 2. 配置 AI

1. 打开“模型与设置”，选择 DeepSeek、Kimi、OpenAI / GPT 等服务商。
2. 填入该平台的 API Key。默认地址和模型名称可修改，模型名称必须是服务商支持的 API 标识。
3. 保存并测试连接。
4. 在“日常概览使用”中选择服务商；全文解读可单独选择服务商，然后保存通用设置。
5. 若希望获取论文后自动生成概览，启用自动 AI 精筛和摘要选项。

选择服务商卡片是在编辑该服务商配置；日常概览的实际服务商由对应下拉框决定。密钥留空表示保留已保存密钥。模型预设可能随厂商更新而变化，连接失败时先核对 API Key、余额、模型权限和接口地址。

ChatGPT 会员不包含 OpenAI API 额度，API 需要单独计费。其他服务商的聊天会员也不应视为 API 授权。请在平台控制台核对费用，并设置本应用的调用次数和 token 限额。应用金额估算不等于厂商账单。

AI 任务会将任务需要的标题、摘要、选文或正文文字发送到所选服务商。本地保存并不代表所有 AI 处理都在本地完成。

## 3. 收藏与阅读

收藏论文后，可以设置阅读状态、集合和标签。开放 PDF 可下载到本机；没有可用开放附件时，可导入自己有权使用的 PDF。也支持 DOI、arXiv 链接及 BibTeX / RIS 导入。

阅读器支持缩放、目录、搜索跳页、文字模式与进度恢复。选中文字后可翻译、解释、记笔记或高亮。AI 功能需配置可用模型。扫描版 PDF 需要先自行 OCR。

简短概览主要依据摘要；全文解读依据已提取正文文字；阅读问答依据当前页和选文。请结合标明的依据范围核对结论、公式与引用页码。

## 4. 经典论文与学习资源

经典清单提供少量有教材或官方技术文档依据的种子论文，可手动补充。它不是全领域“必读”排名。

课程库提供精选免费资源和知识点匹配，可保存自选链接、记录学习状态，也可通过 B 站入口继续搜索。第一版不自动抓取 B 站全站视频。

## 5. Zotero

在 Zotero 官网账户设置中创建个人文献库 API Key，并授予所需读写权限。在本应用设置中填写连接信息，测试连接后选择集合。

可以手动导入文献、保存条目、导出总结和笔记，以及按需上传 PDF。上传附件会占用 Zotero 文件存储空间。当前仅支持个人库，不包含自动双向同步、群组库、WebDAV 或 Zotero 批注同步。

## 6. 备份与迁移

通过应用导出 ZIP 备份，包含论文数据库内容和 PDF，不包含服务商密钥、用量及 AI 缓存。换电脑后安装应用并恢复备份，再重新填写密钥。恢复为按 ID 合并，不覆盖当前同 ID 内容。

`data/` 是本地运行数据目录，不应提交到 GitHub。整个目录包含加密密钥文件；直接复制该目录时应像保管账户凭据一样妥善保管。

## 常见问题

- **没有推荐：**检查方向关键词、近期日期范围、来源错误和候选过滤结果。
- **模型报错：**检查余额、模型 API 标识、密钥所属平台及网络。会员订阅与 API 计费可能独立。
- **页面打不开：**确认后端已启动、前端已构建，并访问 `http://127.0.0.1:8765`。
- **每天没有自动获取：**电脑休眠或后端关闭时任务不会执行，重启会补查当天。
- **能否放到公网：**当前是本地单用户应用，没有公网登录与多用户隔离。
- **更新源码：**先在应用中备份数据，拉取更新后重新运行安装与构建流程，再重启服务。
